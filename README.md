# Banking Database Management System using SQL

This project simulates real-world banking operations such as customer management, account handling, loan processing, and transaction tracking.

## 🎯 Objective
- Manage banking data efficiently  
- Maintain relationships between customers, accounts, loans, and transactions  
- Perform data analysis using SQL queries  
- Extract meaningful insights from financial data  

## 🗂️ Database Tables
**Customers**, **Accounts**, **Loans**, and **Transactions** — each linked through primary and foreign keys to represent real banking relationships.

## 🧠 SQL Queries Summary
Total **36 queries** covering:
- Basic (Data retrieval)  
- Intermediate (Aggregation & grouping)  
- Advanced (Business analysis)  
- Joins & Views (Data abstraction and summaries)

## 🔍 Key Features
- Customer management system  
- Account tracking system  
- Loan management system  
- Transaction monitoring system  
- Data analysis using SQL  

## 📊 Insights
- High-balance customers identified  
- Cities with higher banking activity  
- Inactive accounts detected  
- High-risk customers analyzed  
- Credit transactions more frequent  

## 🏁 Conclusion
This project demonstrates SQL-based banking data management and analysis.  
It helped in understanding joins, grouping, aggregation, and views — improving real-world problem-solving skills.
